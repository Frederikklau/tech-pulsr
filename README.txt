TECH PULSE – iPhone-only Version

WICHTIG: Diese Version braucht keinen Windows-PC und keinen eigenen Server.
Sie ist eine statische Web-App (PWA). Die News werden über Google News RSS und
den öffentlichen RSS-Konvertierungsdienst rss2json.com abgerufen.

SO INSTALLIERST DU SIE NUR MIT DEM IPHONE:

1. Lade TECH-PULSE-iPhone.zip in die Dateien-App.
2. Öffne https://app.netlify.com/drop in Safari.
3. Melde dich bei Netlify an oder erstelle ein Konto.
4. Entpacke die ZIP-Datei in der Dateien-App (einmal auf die ZIP tippen).
5. Öffne den entpackten Ordner. Wähle den Ordnerinhalt für den Upload bei Netlify
   aus. Falls die Netlify-Seite auf dem iPhone den Ordner-Upload nicht anbietet,
   nutze GitHub in Safari: Erstelle ein Repository und lade die vier Web-Dateien
   index.html, manifest.webmanifest, sw.js und die Icons hoch. Aktiviere danach
   GitHub Pages unter Settings > Pages > Deploy from a branch > main / root.
6. Öffne die veröffentlichte HTTPS-Adresse in Safari auf dem iPhone.
7. Tippe auf Teilen > Zum Home-Bildschirm > Hinzufügen.

HINWEISE:
- Das iPhone benötigt eine HTTPS-Adresse, damit die PWA installiert werden kann.
- News-Abruf ist von der Verfügbarkeit und den Limits des öffentlichen RSS-Dienstes
  abhängig. Bei Störungen kann der letzte gespeicherte News-Stand angezeigt werden.
- RSS-Titel und Kurzbeschreibungen sind nicht automatisch Faktenchecks. Öffne
  wichtige Meldungen immer über den Originalartikel.
- Das ist eine Web-App und keine native App aus dem App Store.
